# ascend — 8-Week Program landing page

Landing page for the **Ascend 8-Week Program** by Kudret Muminov ([@muminov.ascends](https://www.instagram.com/muminov.ascends/)).

**Live site:** https://kudret05.github.io/ascend/

## What's on the page

- Hero with the program offer ($4.99, 3–4 days a week, beginner friendly)
- What the program includes: workouts, two phases, nutrition guide, weekly tracker
- Product library (program, upcoming home edition and meal plan, 1:1 coaching)
- Before/after transformation story
- FAQ, money-back guarantee and disclaimer
- Payment popup that sends buyers to Instagram DMs

## Design

Clean, Apple-inspired layout: Inter typeface, one blue accent, soft grey sections and black contrast blocks for the story and guarantee. Mobile-first, since most visitors come from TikTok and Instagram.

## Tech

Static HTML, CSS and a few lines of vanilla JavaScript for the payment popup. No frameworks, no build step. Hosted on GitHub Pages. Designed and built with AI-assisted tools (Claude).
